# 수업 도구 모음

영어 과외·수업용 웹 도구 모음. 설치·서버 없이 HTML/CSS/JS만으로 동작하고 GitHub Pages로 공개한다.

| 페이지 | 설명 |
| --- | --- |
| `index.html` | 도구 메뉴 |
| `word-test.html` | 단어 목록을 붙여넣어 뜻쓰기·영어쓰기·혼합·객관식(4지선다) 테스트지와 답지를 만들고 인쇄/PDF 저장. '한 장에 맞추기'로 A4 한 장에 맞게 글자 크기 자동 조절 |
| `escape-room.html` | 문제·정답·힌트를 입력해 방탈출 게임 만들기. 프로젝터용 플레이, 학생용 공유 링크(`#play=...`), 효과음(Web Audio, 음소거 가능), 게임 파일(.json) 저장/불러오기 |
| `style.css` | 공통 스타일 (라이트/다크) |

## 규칙
- 빌드 도구·외부 라이브러리 없이 순수 HTML/JS 유지 (GitHub Pages에 그대로 올라가야 함)
- 화면 문구는 한국어
- 입력한 내용은 브라우저 `localStorage`에만 저장 (서버 없음)
- 휴대폰 화면(폭 375px)에서도 깨지지 않게
